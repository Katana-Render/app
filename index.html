Mesin

Enam jenis animasi web, satu aplikasi.

CSS Keyframes

Animasi @keyframes dan transition diambil per frame dari jam virtual.

@keyframes slash { to { transform: translateX(100%) } }
  • Loader, transisi UI, teks kinetik
  • Cukup HTML dan CSS

GSAP

Tween dan timeline GSAP dikunci ke jam virtual, jadi tiap frame jatuh tepat di waktunya.

gsap.timeline().to(".blade", { x: 600, ease: "power4.out" })
  • Motion graphic berlapis
  • Urutan dan easing presisi

Timeline

Animasi berbasis garis waktu: urutan, jeda, dan tumpang-tindih antar elemen dirender sesuai posisinya.

tl.add(intro).add(scene, "-=0.4").seek(2.4)
  • Intro, outro, dan lower third
  • Banyak adegan dalam satu proyek

Canvas 2D

Gambar Canvas 2D digambar ulang tiap frame.

ctx.clearRect(0, 0, w, h); ctx.arc(x, y, r, 0, Math.PI * 2)
  • Partikel dan generative art
  • Grafik data bergerak

Three.js

Scene 3D WebGL lengkap dengan kamera, cahaya, dan model.

renderer.render(scene, camera)
  • Logo 3D dan produk
  • Sampai video 4K

GLSL Raymarching Shader

Shader fragment dengan ray marching: bentuk 3D lahir dari rumus matematika, dihitung per piksel.

float d = map(ro + rd * t); t += d;
  • Visual abstrak dan fraktal
  • Latar loop yang bersih
